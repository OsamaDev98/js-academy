# JS Academy

مشروع Next.js احترافي لمذاكرة JavaScript وAsync JavaScript وNode.js.

## تشغيل محلي
npm install
npm run dev

## Build
npm run build
npm start

## Routing
الدروس تستخدم App Router وDynamic Route:
/learn/[slug]

## Vercel
ارفع المشروع إلى GitHub ثم اختر المستودع من Vercel. لا تحتاج إعدادات خاصة؛ Vercel يتعرف على Next.js تلقائيًا.
